# мусоровоз

Нативное SwiftUI-приложение для macOS, которое показывает, чем занят диск, и аккуратно очищает восстанавливаемые кэши. Категории отображаются блобами, размер которых пропорционален занятому месту. Любое удаление требует подтверждения.

> Интерфейс только на русском. Требуется macOS 15 или новее, Apple Silicon или Intel.

## Что умеет

- Анализ кэшей разработки (npm, npx, pnpm, Bun, pip, uv), Xcode DerivedData и кэшей приложений.
- Очистка восстанавливаемых данных Telegram, Claude, Codex, Yandex Browser и VS Code. Если приложения нет, категория показывает 0.
- Поиск до 20 крупных файлов от 500 МБ в домашней папке через индекс Spotlight.
- Поиск установщиков и архивов (`.dmg`, `.pkg`, `.zip` и т. п.) в `~/Downloads`.
- Отдельные, усиленно подтверждаемые действия для моделей Hugging Face и VM Claude/Cowork.
- Светлая, тёмная и системная темы.

Двойной клик или прокрутка вниз над блобом открывает его состав. Прокрутка вверх возвращает назад.

## Что и как удаляется

| Что | Как | Когда |
| --- | --- | --- |
| Кэши приложений и разработки | удаляются насовсем (`rm -rf`), но создаются заново | кнопка **Очистить всё** и пресеты |
| Модели ИИ, Claude VM | удаляются насовсем, потребуется повторная загрузка | только отдельной кнопкой с отдельным подтверждением |
| Крупные файлы и установщики из `~/Downloads` | **перемещаются в Корзину** | только вручную: по одному или кнопкой **В Корзину всё** |

Блок **Крупные файлы** может показать файлы из любой части домашней папки, включая `Documents`. Они не удаляются автоматически и попадают только в Корзину, откуда их можно восстановить. Внимательно проверяйте список перед подтверждением.

Кэши удаляются только из заранее заданного списка папок, и каждый путь дополнительно проверяется в `validate_target`. Никогда не удаляются:

- профили, пароли, cookies и IndexedDB браузеров;
- база сообщений и настройки Telegram (`postbox/db`);
- история и сессии Codex;
- VS Code `User`, `WebStorage`, `workspaceStorage`, `History`, `globalStorage`, `Backups`;
- Docker images/volumes и проектные `node_modules`.

Если связанное приложение запущено, его кэши пропускаются. Перед очисткой лучше закрыть Telegram, Claude, VS Code, Codex и Yandex.

Журнал операций: `~/Library/Logs/MacCare-cleaner.log`.

## Установка

1. Скачайте `мусоровоз-<версия>.dmg` из раздела **Releases**.
2. Откройте образ и перетащите `мусоровоз.app` в **Программы**.
3. При первом запуске macOS сообщит, что не может проверить разработчика: приложение не нотаризовано Apple.
4. Откройте **Системные настройки → Конфиденциальность и безопасность**, прокрутите вниз и нажмите **Всё равно открыть** напротив «мусоровоз». Затем подтвердите запуск.

На macOS 15 правый клик → **Открыть** это предупреждение больше не обходит, нужен именно пункт в настройках.

Альтернатива для опытных пользователей:

```zsh
xattr -dr com.apple.quarantine /Applications/мусоровоз.app
```

## Сборка из исходников

Нужны Xcode или Command Line Tools (`xcode-select --install`).

```zsh
./build.sh          # build/мусоровоз.app
./build.sh --dmg    # плюс build/мусоровоз-<версия>.dmg
```

Сборка создаёт универсальный бинарник (arm64 + x86_64) и подписывает его ad-hoc подписью.

## Командная строка

Движок очистки — обычный zsh-скрипт `Resources/MacCare.command`, его можно запускать отдельно:

```zsh
Resources/MacCare.command --scan          # только анализ
Resources/MacCare.command --clean-safe    # npm/npx, pip, uv, Bun, кэши Codex и Yandex
Resources/MacCare.command --clean-dev     # то же + старые версии Codex и pnpm store prune
Resources/MacCare.command --clean-apps    # Telegram media/cache, Claude и VS Code
Resources/MacCare.command --clean-models  # кэши Hugging Face
Resources/MacCare.command --clean-claude-vm
Resources/MacCare.command --clean-all     # то же, что кнопка «Очистить всё»
```

Каждый режим спрашивает подтверждение. Флаг `--yes` пропускает вопрос, используйте его только после проверки `--scan`.

## Структура

- `Sources/Models/CleanupModels.swift` — модели категорий, форматирование размеров, режимы очистки;
- `Sources/Models/DashboardViewModel.swift` — состояние экрана, анализ и очистка;
- `Sources/Services/CleanerService.swift` — запуск встроенного скрипта, разбор JSON, перемещение в Корзину;
- `Sources/Views/BlobViews.swift` — блобы, контурная физика, вложенная навигация;
- `Sources/Views/DashboardView.swift` — главный экран, пресеты и журнал;
- `Resources/MacCare.command` — список путей, проверка разрешённых директорий и удаление;
- `build.sh` — сборка приложения, иконки и `.dmg`.

### Как добавить новую папку для очистки

1. Добавьте путь в одну из групп в начале `Resources/MacCare.command`.
2. Добавьте разрешённый префикс в `validate_target`, иначе удаление будет заблокировано.
3. Для отображения блоба добавьте запись в `scan_json` и обработку ID в `clean_blob_node`.

Не добавляйте пути к документам, проектам, базам сообщений и настройкам пользователя.
